Problem and purpose

Text embedded in scans, document images, or handwriting is not immediately available as editable text. This project explores extracting that text through an OCR model and provides a browser demo for submitting an image and reviewing the returned result.

How the demo works

  • Select or drop an image in the browser interface.
  • The image is sent to an OCR API for extraction.
  • Review or copy the extracted text from the result panel.
  • The demo accepts image uploads up to 5 MB.

The live demo supports Arabic, English, French, and handwritten content, allowing visitors to test the extraction workflow directly with their own document image.

My role and implementation

Yahya Mahroof built the OCR model, the Python processing service, the API integration, and the browser workflow for uploading an image and reviewing the extracted result.
