تصميم أنظمة ذكاء اصطناعي للاستخدام العملي

يحيى معروف مهندس ذكاء اصطناعي يعمل على تصميم أنظمة ذكية وتطويرها ونشرها، إلى جانب بناء تطبيقات الويب والخدمات الخلفية.

يستخدم Python وأطر Flask وDjango وFastAPI، ويطوّر وكلاء ذكاء اصطناعي ويدمجها ضمن حلول واقعية. تشمل خبرته نشر التطبيقات على خوادم Ubuntu، وواجهات REST API وWebSockets والأنظمة الفورية.
